# UI Component Library (Custom — not shadcn)

Components follow Impeccable anti-pattern rules: no purple gradients, single electric blue accent, flat groups separated by whitespace.

- `Button`: Rounded-full, 150ms ease-out, electric blue or slate border
- `Input`: Rounded-lg, border with [var(--color-border)], focus-ring
- `Card`: Rounded-2xl, bg-[var(--color-bg-alt)], single border
- `Tabs`: Underline border transition
- `Badge`: Rounded-full, small text, single accent tint

No nested cards, no decorative icon clutter, no gradient backgrounds.
